# Coverage Map v1.1.4

Format canonique: `Spec -> Code -> Tests -> Issues -> Status`

## Zones couvertes

- Sécurité des dépendances npm
  - Code: `package.json`, `package-lock.json`
  - Vérifications: resolutions verrouillees pour les dependances concernees; revue des alertes Dependabot de develop
  - Issues: alertes de securite sur les dependances directes et transitives
  - Status: `corrige sur develop`

- Qualite et maintenabilite
  - Code: `components/`, `src/`, `utils/`, `views/`
  - Tests: `tests/unit`, `npm run lint`, `npm run typecheck`, `npm run test:unit:coverage`, `npm run governance:coverage`, `npm run build`
  - Issues: constats Sonar de maintenabilite, APIs obsoletes, accessibilite et complexite
  - Status: correctifs et tests presents sur `develop` et `release/v1.1.4`; confirmation SonarCloud en attente

- Regression des refactorings de release
  - Code: `components/game/CapitalKeypad.tsx`, `views/CapitalStatsView.tsx`, `src/features/game-setup/`, `utils/arenaFlow.ts`
  - Tests: `tests/unit/components/capitalKeypad.test.tsx`, `tests/unit/components/capitalStatsView.test.tsx`, `tests/unit/gameSetup/`, `tests/unit/arenaFlow.test.ts`
  - Issues: couverture insuffisante du nouveau code dans la PR [#188](https://github.com/floriangiral/Bougnat_darts_counter/pull/188)

## Limites

- la branche `release/v1.1.4` existe et la PR #188 est ouverte vers `main`, sans fusion ni promotion;
- le Quality Gate de la PR et le nouveau smoke E2E doivent etre confirmes avant fusion;
- la couverture globale locale n'est pas equivalente a la couverture SonarCloud du nouveau code;
- aucune modification des regles metier de scoring n'est incluse;
- les dependances runtime distantes et les integrations metier restent hors perimetre.
