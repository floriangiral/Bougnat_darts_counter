## Limites

- ces nouveaux tests doivent etre commites/pousses puis repris explicitement
  dans la release avant de pouvoir etre valides par la CI de cette branche;
- la couverture globale locale n'est pas equivalente a la couverture SonarCloud du nouveau code;
- la mesure SonarCloud et le Quality Gate restent a confirmer apres publication;
- aucune modification des regles metier de scoring n'est incluse dans cette campagne;
- les tests de streaming simulent les frontieres audio/SDK/token: ils ne
  remplacent pas un essai reel de microphone et de connexion Deepgram.
