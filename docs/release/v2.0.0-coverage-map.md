## Limites

- La suite E2E complete Chromium (dont `pwa.smoke`) est executee par la CI de la PR ; WebKit n a pas ete execute.
- Le lien externe n a pas ete essaye avec une application partenaire reelle (contact non autorise) ni sur un iPad physique.
- L affichage telephone n a ete verifie que dans Chrome (emulation Playwright), ni sur un telephone physique ni dans Safari iOS. Le verrouillage portrait a été retiré (spec 028).
- Chantier « refonte tablette et thèmes » : les E2E `tablet-layout`, `smartphone-layout` et `theme` sont écrits mais non exécutés localement ; aucune vérification sur tablette, téléphone ou iPad réels ; captures de référence Dark/Light et axe-core à produire (spec 041). Le défaut 1024x600 (score minuscule, touches d environ 26 px) est corrigé dans le code, non vérifié sur appareil.
- Sur les ecrans de hauteur utile <= 568 px, le score de la zone joueur est entier mais petit (environ 28 px).
- Les fenetres de PC larges et basses ne sont plus en presentation telephone : la suite E2E Chromium (1280x720) tourne desormais en presentation par defaut ; elle n a pas ete reexecutee.
- Application installable : en-tetes HTTP, mise a jour pendant une partie, installation Android et iOS a valider en preprod et sur appareil.
- Les validations locales ne remplacent pas la couverture du nouveau code et le Quality Gate SonarCloud.
- La branche de release n est pas un tag ni une livraison production.
