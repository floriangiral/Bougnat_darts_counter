# Release v1.1.3

## Statut

- release de stabilisation qualite
- branche de travail: `release/v1.1.3`
- version package: `1.1.3`
- date: 25/08/2026
- objectif: reduire la dette SonarCloud historique sans modifier les regles metier

## Changements

### Qualite SonarCloud

- correction des issues de style et de modernisation sans impact fonctionnel;
- suppression des neutralisations `void` inutiles;
- initialisation IndexedDB differee hors constructeur;
- reduction de la complexite du reducer Capital;
- types de boutons HTML explicites;
- modernisation des API DOM, collections, exports et normalisation de chaines;
- ajout de tests Setup, changelog et utilitaires fullscreen;
- couverture locale: 165 tests et seuils Vitest de non-regression.

### CI et documentation

- analyse SonarCloud du New Code sur les pull requests;
- analyse globale sur `main` apres merge et chaque semaine;
- resume des metriques SonarCloud publie dans le Summary GitHub Actions;
- analyse Snyk des dependances npm avec seuil bloquant `high`;
- correction du job Snyk pour installer les dependances avant l analyse;
- scan Snyk Container de l image Docker avec seuil bloquant `high`;
- image Docker locale basee sur Alpine, sans npm dans le runtime final, pour reduire la surface de vulnerabilites;
- version affichee dynamiquement sur l accueil depuis `package.json`;
- changelog de l accueil et documentation generale alignes sur `v1.1.3`.

## Compatibilite metier

Aucune regle de scoring, aucun parcours de jeu et aucune interface publique de scoring ne sont modifies par cette release. Les corrections concernent la qualite statique, la couverture de tests, la documentation et la robustesse technique.

## Verification

- `npm run lint`
- `npm run typecheck`
- `npm run test:unit`
- `npm run test:unit:coverage`
- `npm run build`
- Quality Gate SonarCloud du New Code
