# Release v1.1.5

> Release historique. Derniere version preparee : [v2.0.0](v2.0.0.md) (non publiee).

## Statut

- Date de preparation : 19 novembre 2026.
- Version applicative : `1.1.5`, commune au manifeste, au lockfile et au label d accueil injecte par Vite.
- Branche de release : `release/v1.1.5`, issue de `develop` avec les lots de maintenance valides.
- Publication de branche uniquement : aucun tag, GitHub Release, merge vers `main` ou deploiement production implicite.
- Les resultats GitHub Actions, SonarCloud et Snyk restent a confirmer sur la branche publiee.

## Securite et dependances

- Undici `7.30.2` corrige les six alertes Snyk initiales (une critique et cinq elevees). jsdom utilise separement Undici `8.12.4`.
- React et React DOM `19.3.1` restent alignes.
- Mise a jour des dependances applicatives et de developpement : Deepgram `5.20.0`, Lucide `1.76.0`, Tailwind `4.3.5`, Vite `8.3.8`, Vitest `5.1.1`, ESLint `10.15.0`, Wrangler `4.165.0` et Testing Library React `16.3.3`.
- Plugin React Vite `6.3.0`, jsdom `31.0.1` et TypeScript `6.0.3`.
- Les overrides restent sur les dernieres branches compatibles : Babel 7, Nanoid 3 et `@humanfs/node` 0.16. TypeScript 7 reste exclu car TypeScript-ESLint `8.73.0` exige `<6.1.0`.
- Retrait du paquet deprecie `node-domexception` via un override `formdata-node` `6.0.3` limite au SDK Cloudflare. Tests de contrat multipart HTTP CommonJS/ESM et garde-fou contre les paquets marques `deprecated` dans le lockfile.

- Node `24.22.3` LTS commun a `.nvmrc`, la CI et l image applicative ; types Node `24.19.2`.
- npm `12.2.3` declare explicitement ; installation par `npm ci`, sans repli pnpm/Corepack.
- Scripts de dependances autorises uniquement pour les versions verrouillees d esbuild et workerd ; banniere core-js refusee sans retirer les polyfills.
