# Release v1.1.4

## Statut

- patch de securite et de maintenance
- version package: `1.1.4`
- branche cible: `release/v1.1.4` (à créer depuis `develop` après validation)
- changements préparés et poussés sur `develop`; la promotion de release n'a pas encore eu lieu

## Changements

### Securite des dependances

- mise à jour des dependances npm directes et transitives concernees par les alertes Dependabot;
- mise à jour des versions verrouillees et des resolutions npm pour corriger les alertes de securite sans modifier les dependances runtime metier.

### Maintenance et qualite

- traitement des constats Sonar sur la complexite, les types, les composants UI et l'accessibilite;
- remplacement d'API obsoletes et modernisation des operations sur les tableaux et le clonage de donnees;
- amelioration des dialogues et des cles de rendu React.

## Compatibilite metier

Aucune regle de scoring ni aucun parcours de jeu n'est intentionnellement modifie. Les parties locales et le mode offline-first restent inchanges.

## Verification

- `npm run lint`
- `npm run typecheck`
- `npm run test:unit`
- `npm run build`
