# Release v1.1.4

## Statut

- patch de securite et de maintenance
- version package: `1.1.4`
- branche de release: `release/v1.1.4`, creee depuis `develop`
- PR vers `main`: [#188](https://github.com/floriangiral/Bougnat_darts_counter/pull/188)
- correctifs CI `6a0d781` et `5f3879b` presents sur `develop` et sur la branche de release
- les prochaines modifications sont preparees sur `develop`, puis integrees a la branche de release
- aucune fusion vers `main`, aucun tag ni deploiement effectue a ce stade

## Changements

### Securite des dependances

- mise à jour des dependances npm directes et transitives concernees par les alertes Dependabot;
- mise à jour des versions verrouillees et des resolutions npm pour corriger les alertes de securite sans modifier les dependances runtime metier.

### Maintenance et qualite

- traitement des constats Sonar sur la complexite, les types, les composants UI et l'accessibilite;
- remplacement d'API obsoletes et modernisation des operations sur les tableaux et le clonage de donnees;
- amelioration des dialogues et des cles de rendu React.
- ajout de tests de regression pour le clavier Capital, les statistiques Capital, les modeles de configuration et le routage des jeux.

## Compatibilite metier

Aucune regle de scoring ni aucun parcours de jeu n'est intentionnellement modifie. Les parties locales et le mode offline-first restent inchanges.

## Verification

- `npm run lint`
- `npm run typecheck`
- `npm run test:unit`
- `npm run test:unit:coverage`
- `npm run governance:coverage`
- `npm run build`

### Resultats locaux sur les correctifs CI

- 207 tests reussis dans 43 fichiers;
- couverture globale: 84,28 % des instructions, 74,91 % des branches, 85,42 % des fonctions et 85,67 % des lignes;
- lint, typecheck, build et gouvernance de couverture reussis, sans abaisser les seuils ni ajouter d'exclusions.

### Validation SonarCloud et CI de release

- la premiere analyse de la PR a echoue sur la couverture du nouveau code: 62,4 % pour un seuil de 80 %;
- six constats Sonar residuels ont ete corriges et des tests ont ete ajoutes;
- la nouvelle execution [Quality Gate](https://github.com/floriangiral/Bougnat_darts_counter/actions/runs/41657850227) reste en attente de resultat final au moment de cette mise a jour;
- la couverture globale locale ne confirme pas le seuil Sonar du nouveau code: le resultat serveur doit etre verifie avant fusion;
- l'analyse de PR fonctionne, contrairement a la tentative d'analyse de `develop` seule, bloquee par les restrictions SonarCloud sur les branches secondaires;
- le smoke E2E initial a reussi; sa nouvelle execution sur les correctifs reste a confirmer.
