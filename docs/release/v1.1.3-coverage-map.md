# Coverage Map v1.1.3

Format canonique: `Spec -> Code -> Tests -> Issues -> Status`

## Zones couvertes

- `spec:counter/release-v1.1.3-sonar-debt`
  - Code: `package.json`, `README.md`, `docs/`, `components/`, `src/`, `utils/`, `views/`, `.github/workflows/`
  - Tests: `tests/unit`, `npm run test:unit:coverage`, `npm run lint`, `npm run typecheck`, `npm run build`
  - Issues: dette SonarCloud historique et stabilisation CI
  - Status: `partiellement couvert`

- `spec:counter/security-review`
  - Code: `.github/workflows/security-review.yml`, `SECURITY.md`, `CONTRIBUTING.md`
  - Tests: CodeQL, Gitleaks, Dependency Review, `npm audit`, Snyk Dependencies, Snyk Container
  - Issues: controles de securite et audit de dependances
  - Status: `couvert` pour la CI; dette historique Sonar suivie dans SonarCloud

## Limites connues

- les refactors de complexite cognitive des grandes vues restent a traiter par lots dedies;
- la couverture globale et la couverture du New Code sont suivies par SonarCloud;
- les tests E2E couvrent les parcours critiques mais pas toutes les combinaisons de jeux et d environnements.

## Hors perimetre

- changement des regles metier de scoring;
- backend metier, authentification distante et logique tournoi;
- modification des secrets ou de la configuration runtime Cloudflare.
