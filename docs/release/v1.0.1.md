# Release v1.0.1

## Statut

- stable
- open source
- centree sur le scorage et l offline-first
- date de consolidation: `2026-04-24`

## Resume fonctionnel

- moteur de scoring maintenu sur `X01`, `501 Double Out`, `Cricket`, `Capital`, `Triathlon`
- sessions locales et reprise locale confirmees
- voice scoring `X01` conserve en mode optionnel avec fallback manuel
- flux critiques de partie conserves: lancer, scorer, corriger, annuler, terminer

## Resume technique

- suppression du flag frontend legacy `VITE_ENABLE_ANALYTICS`
- validation Deepgram renforcee avant promotion `preprod` et `production`
- validation de projet Deepgram ajoutee dans la generation de token backend local/vercel
- execution E2E locale stabilisee via worker unique par defaut

## Verification release

- `npm run ci:check`: OK
- `npm run test:e2e` avec preview local: OK (en sequence)
- `npm run preprod:check`: KO local attendu sans variables d environnement cible
- `npm run production:check`: KO local attendu sans variables d environnement cible

## Hors perimetre confirme

- backend metier proprietaire
- authentification riche
- profils distants
- statistiques cloud consolidees

- le voice scoring depend d un service externe optionnel
