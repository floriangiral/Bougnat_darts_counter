# Release v1.0.1

## Statut

- stable
- open source
- recentree sur le scorage
- lisible et publiable
- date de consolidation: `2026-04-24`

## Ce qui a evolue

- experience de jeu plus fluide sur les ecrans principaux
- navigation et affichage mieux harmonises entre mobile et desktop
- structure interne plus lisible et plus simple a faire evoluer
- repères d environnement plus clairs sur l accueil en dev et preprod
- QR de partage aligne sur l URL reelle de l environnement

## Ameliorations transverses

- code davantage decoupe par responsabilite
- surfaces techniques inutiles reduites
- maintenance et verification plus simples
- meilleure separation entre le socle de scorage et les responsabilites hors perimetre

## Ce qui reste volontairement inchange

- le comportement metier existant
- les modes de jeu supportes
- la logique de scoring deja en place

## Hors perimetre

- backend metier proprietaire
- authentification riche
- statistiques cloud consolidees
- logique tournoi avancee
- persistance distante du contenu metier

## Note

Cette release reste volontairement sobre sur le fonctionnel visible, mais elle consolide le socle pour les prochaines evolutions.
