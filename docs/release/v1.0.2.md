# Release v1.0.2

## Statut

- stable
- open source
- centree sur le scorage et l offline-first
- date de consolidation: `2026-04-27`

## Resume fonctionnel

### Nouveaux modes de jeu
- **Gotcha** : mode complet avec regles metier formalisees, integration dans le setup, le flux de partie et l UI mobile
- **Killer** : mode Killer disponible dans la selection et le runtime, avec mise a jour du setup

### Ameliorations
- **Raccourci installation** : bouton "Ajouter a l ecran d accueil" sur la page d accueil avec prompt dedie
- **Stats X01** : label `CHECKOUT` en remplacement de `sorties` pour plus de clarte
- **Score layout** : affichage resilient au zoom systeme OS — `rem` remplace par `px`/`vw+svh` — prevention du debordement sur petit ecran et des chevauchements pill/badge
- **Performance INP** : reactivite des boutons amelioree (`onPointerDown`, debounce persistance 300ms, suppression du double-write localStorage)

### Corrections
- Fix scroll parasite lors de la selection de partie sur smartphone
- Compatibilite legacy iOS 12 retablie pour les anciens iPad (iPad Air)

## Resume technique

- spec `016-counter-gotcha-mode` : regles domaine, tests, integration UI
- spec `020-counter-inp-phase1-quick-wins` : 3 optimisations INP mesurables
- spec `021-counter-score-layout-font-scale-resilience` : layout immunise au font-scale OS
- `@types/react` et `@types/react-dom` ajoutes aux devDependencies, `tsconfig.json` corrige (types array)
- observabilite : `screen_view` tracking + flags `GOTCHA`/`KILLER`
- nettoyage : zero reference Supabase dans les fichiers trackes
