# Release v1.0.2

## Statut

- stable
- open source
- centree sur le scorage et l offline-first
- date de consolidation: `2026-04-27`
- issue de pilotage release: `#91`

## Resume fonctionnel

### Nouveaux modes de jeu
- **Gotcha** : mode complet avec regles metier formalisees, integration dans le setup, le flux de partie et l UI mobile
- **Killer** : mode Killer disponible dans la selection et le runtime, avec mise a jour du setup

### Ameliorations
- **Raccourci installation** : bouton "Ajouter a l ecran d accueil" sur la page d accueil avec prompt dedie
- **Stats X01** : label `CHECKOUT` en remplacement de `sorties` pour plus de clarte
- **Score layout** : affichage resilient au zoom systeme OS — `rem` remplace par `px`/`vw+svh` — prevention du debordement sur petit ecran et des chevauchements pill/badge
- **Performance INP** : reactivite des boutons amelioree (`onPointerDown`, debounce persistance 300ms, suppression du double-write localStorage)

### Corrections
- Fix scroll parasite lors de la selection de partie sur smartphone
- Compatibilite legacy iOS 12 retablie pour les anciens iPad (iPad Air)
- Installation Vercel alignee sur npm via `packageManager` explicite et `installCommand` stable
- Lockfile normalise sur `registry.npmjs.org` pour eliminer la dependance a un registre prive historique

## Resume technique

- spec `019-counter-gotcha-game` : regles domaine, tests, integration UI
- spec `020-counter-inp-phase1-quick-wins` : 3 optimisations INP mesurables
- spec `021-counter-score-layout-font-scale-resilience` : layout immunise au font-scale OS
- spec `022-counter-arch-single-responsibility-split` : decoupe des god objects en 5 modules
- `@types/react` et `@types/react-dom` ajoutes aux devDependencies, `tsconfig.json` corrige (types array)
- observabilite : `screen_view` tracking + flags `GOTCHA`/`KILLER`
- nettoyage : zero reference Supabase dans les fichiers trackes
- suppression du type `X01_501_BO5` et de la logique `isQuickPreset` (dette de simplification)

### Architecture SRP (spec 022)
- `App.tsx` : 530 → 347 lignes — lifecycle handlers extraits dans `src/app/useGameLifecycle.ts`
- `MatchView.tsx` : 892 → 848 lignes — timer dans `useMatchTimer.ts`, shortcuts dans `useMatchShortcuts.ts`
- `setupModel.ts` : 609 → 459 lignes — presentation extraite dans `setupPresentation.ts`
- `analyticsInstance.ts` : singleton partagé, plus de double instanciation possible

### Corrections CI pré-release
- `initialStartingTeamId` : type resserré `string` → `'team1' | 'team2'`
- `vi.fn<Args,Ret>` → `vi.fn<Sig>` (API Vitest 4 breaking)
- ESLint `no-unused-expressions` : Keypad.tsx corrigé
- `package.json` version alignée sur v1.0.2
- ESLint `react-hooks/refs` desactive globalement — faux positif React 18 / Node 24 (rule introduite pour React 19 Compiler)
- Keypad.tsx : `clearLongPress` et `startLongPress` encadres par `useCallback` — stabilite des callbacks
- `vercel.json` : abandon du chemin `npm ci` fragile au profit d une installation npm explicite avec devDependencies
- `.npmrc` : registre public npm force pour la reproductibilite CI et Dependabot

### Corrections visuelles et nommage (iteration finale)
- **Renommage Triathlon** : "Le Triathlon" renomme en "Triathlon" — coherence avec Cricket, Capital, Gotcha, Killer, X01
- **Couleurs par jeu** : chaque jeu possede son propre gradient d accent et sa couleur de fleche dans la page de selection
  - X01 : orange, Triathlon : jaune/amber, Cricket : emerald, Capital : violet/fuchsia, Gotcha : cyan, Killer : rose
- **Smoke e2e refactores** : tests de restauration de session seedee remplaces par 6 tests de navigation independants (un par jeu)
  — suppression de `session-fixtures.ts` (131 lignes de payloads fragiles)
