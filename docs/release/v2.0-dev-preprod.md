# Release 2.0 dev/preprod

La release 2.0 du counter est limitee aux environnements local/dev/preprod. La production reste sur le comportement 1.1 jusqu'a decision explicite.

## Active en dev/preprod

- Connexion frontend via Clerk avec JWT API demande sur le template `bougnat-darts-api`.
- Backend canonique via `VITE_TOURNAMENT_API_BASE_URL`.
- Espace joueur connecte: profil, photo synchronisee, stats, matchs, tournois et preferences scoring.
- Preparation scoring tournoi: ports applicatifs, adapter HTTP, mapper X01 isole et brouillon local de soumission.
- Parcours mock connecte non-production via `?auth=mock` pour smoke E2E et validation preprod sans compte reel.

## Desactive en production

- La production garde `VITE_APP_VERSION=1.1.0`.
- Le mode local sans compte reste l'entree principale.
- Le mock `?auth=mock` est ignore quand `VITE_APP_ENV=production`.

## URLs backend

- Dev: `http://localhost:8080`
- Preprod: `https://bougnat-darts-develop.fly.dev`
- Production: `https://api.bougnatdarts.fr`

`VITE_BOUGNAT_API_URL` reste un alias legacy. Aucun secret ne doit etre expose via `VITE_*`.
