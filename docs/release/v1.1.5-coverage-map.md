## Limites

- Les tests unitaires simulent la voix et ne remplacent pas un essai microphone/Deepgram.
- Les validations locales ne remplacent pas la couverture du nouveau code et le Quality Gate SonarCloud.
- Les warnings de services distants ou les nouvelles deprecations editeurs doivent etre controles apres publication ; aucun masquage de logs n est applique.
- La branche de release n est pas un tag ni une livraison production.
