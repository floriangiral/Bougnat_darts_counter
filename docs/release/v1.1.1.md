# Release v1.1.1

> Release historique. La version active est `v1.1.2`.

## Statut

- patch release open source
- branche cible de release: `release/1.1.1`
- version package: `1.1.1`
- scope: stabilisation runtime + alignement documentation + coherence release in-app

## Pourquoi cette patch release

La release `v1.1.1` consolide la base `v1.1` avec des corrections de fiabilite et d alignement documentaire, sans elargir le perimetre produit.

Objectifs :

- supprimer les divergences de version visibles entre l app et la documentation
- corriger un incident de demarrage frontend (ecran blanc)
- renforcer la compatibilite de la configuration Vite
- garder une trace release claire cote Git et docs
