# Release v1.0.0

## Statut

- stable
- open source
- recentree sur le scoring
- date de consolidation: `2026-04-23`

## Ce qui a ete stabilise

- jeux supportes
- saisie de score
- correction et annulation
- fins de manche et de partie
- assistance vocale `X01`
- persistence locale
- reprise locale de session

## Ce qui a ete clarifie

- separation entre moteur de scoring open source et backend metier externe
- trajectoire spec-driven
- Clean Architecture pragmatique
- priorite donnee au mode local offline-first
- couverture du perimetre supporte dans `docs/release/v1.0.0-coverage-map.md`

## Ce qui sort du perimetre

- authentification
- lobby
- profils distants
- historique cloud
- statistiques cloud
- logique tournoi
- persistance backend metier

## Quality Gate local

- `npm run ci:check`: `OK` (lint, typecheck, tests unitaires, build)
- `npm run test:e2e`: `KO environnement` (runner Chromium indisponible localement: `libnspr4.so` manquant)

## Known limitations

- les scenarios E2E necessitent un environnement CI ou poste local avec dependances Playwright systeme installees
- le mode connecte reste optionnel et non actif par defaut en `v1.0.0`
